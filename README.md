# Shapika Store

A full-stack e-commerce platform built with Next.js, NestJS, TypeScript, and MongoDB.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Zustand
- React Hook Form
- Zod

### Backend
- NestJS
- TypeScript
- MongoDB
- JWT
- Passport
- Swagger

## Features

### Authentication
- User registration and login
- JWT authentication
- HTTP-only cookies
- Role-based access control

### Products
- Product management
- Categories
- Brands
- Search
- Filtering
- Product details

### Shopping
- Shopping cart
- Wishlist
- Orders
- Checkout

## Project Structure

frontend/  → Next.js application
backend/   → NestJS API

## Getting Started

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
npm install
npm run start:dev

## Environment Variables

Create environment files for both frontend and backend.

## API Documentation

Swagger documentation is available through the backend API.
